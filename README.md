# Soft-MMP for Rapid Skin Cancer Screening

This repository provides an **8 × 8 Hall-input interface → 32 × 32 reconstructed map** and a synthetic execution example. Sensor-input heatmaps generated by this public package use an 8 × 8 array. A reconstruction grid represents inferred values, not additional measured sensor sites.

The author-held training and figure records have now been audited. The archived modelled-lesion experiment contains **78 paired cases**, split into **55 training, 8 validation and 15 test lesions**. Its selected checkpoint is **`best.pt`, epoch 196**, and its numerical outputs are linked to **Supplementary Fig. 21**. The exact counts, split membership, checkpoint hash and figure-source hashes are recorded in [DATASET_CARD.md](DATASET_CARD.md) and [provenance/](provenance/).

**Scope matters:** that archived experiment reconstructed on a **64 × 64 numerical grid**. Its 8 × 8 field-display arrays were produced by bicubic resampling of archived field samples. They do not establish native 8 × 8 acquisition or training of the current 8 × 8 → 32 × 32 interface. The public package and the archived experiment are documented separately.

## Public implementation

- Three sigmoid convolutional layers with bicubic upsampling and negative-PSNR loss.
- Explicit sample and independent-group identifiers; checks for groups or identical source files crossing splits.
- Training-only normalization, validation-based checkpoint selection and test evaluation after selection.
- Run summaries with split counts, file hashes, effective settings, software versions and checkpoint provenance.
- One analytic input/target pair for a smoke test: one synthetic pattern, zero biological specimens and zero physical phantoms.

## Quick start

Use Python 3.11 or 3.12. Run from the repository root and use a fresh output directory for each training run.

```bash
python -m pip install -r requirements.txt
python -m srcnn_8x8_to_32x32.infer --input srcnn_8x8_to_32x32/examples/toy_input_8x8.csv --out_dir smoke_test_artifacts/random_demo --smoke_test --device cpu
python -m srcnn_8x8_to_32x32.train --manifest srcnn_8x8_to_32x32/examples/toy_manifest.csv --epochs 1 --out_dir smoke_test_artifacts/toy_training --smoke_test --device cpu
python -m srcnn_8x8_to_32x32.infer --input srcnn_8x8_to_32x32/examples/toy_input_8x8.csv --checkpoint smoke_test_artifacts/toy_training/last.pt --out_dir smoke_test_artifacts/trained_demo --device cpu
```

Random weights require explicit `--smoke_test`. One-pair smoke training has no validation or test split and saves `last.pt`; it cannot measure generalization. Normal inference requires a checkpoint with its training normalization, configuration and provenance. [REPRODUCE.md](REPRODUCE.md) explains the commands and the archive audit.

## Code availability scope

The 8 × 8 to 32 × 32 SRCNN source code, input/output formats, synthetic execution example, and audited metadata for the archived modelled-lesion experiment are publicly available here. The metadata include the 78-case lesion-level split manifest, training settings, normalization values, the identity and SHA-256 of the checkpoint used for the Supplementary Fig. 21 numerical source maps, and per-case figure-source hashes.

The original simulation arrays, modelled modulus targets, trained `best.pt`, dermoscopy probability arrays and manuscript artwork are retained in the author-held study archive and are **not distributed in this repository**. Full manuscript-figure regeneration therefore requires those original assets. The synthetic example and newly trained public-interface checkpoints do not reproduce the manuscript figures or validate the archived experiment's performance. Study-asset enquiries should be directed to the corresponding author; this repository does not grant access to the author-held archive.
